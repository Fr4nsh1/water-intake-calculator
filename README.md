# Water Intake Calculator

Simple tool to calculate how much water you should drink per day based on body weight.

## Formula

Water intake = weight (kg) × 0.035

Example:

70 kg → 2.45 liters of water per day

## Tool

https://botellade.com/calculadora-agua-diaria

## Features

- Calculates daily water intake
- Converts liters to number of bottles
- Simple JavaScript implementation
